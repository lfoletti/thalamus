### Problem
A memory carries `ttl_seconds` and every memory read skips the expired ones, but nothing ever removed them, and a document had no expiry at all. A retention rule, "this source is kept five years, then it goes", had to be enforced by hand with a list of ids.

### Fix
- `ingest_document` takes `expires_at` (RFC 3339). The same key in `metadata` means the same thing, on `ingest_document`, `knowledge_save` and `knowledge_update`; a bad value is refused, a zoned one is stored as UTC.
- A document past its `expires_at` is left out of every retrieval path that reads chunks: lexical, vector, graph walk, `search_text`, the chunk tools, `expand_graph` and every lane of `cortex_query`, through one `{document id → expires_at}` cache reloaded at most every 15 s from an indexed query and dropped by any write. The filter is advisory; the sweep is the guarantee.
- `DB.SweepExpired`, the tool `sweep_expired` and `cortexdb-mcp-stdio --sweep-expired [--dry-run] [--json]` remove the expired documents (record, chunks, graph nodes) and the expired memories (graph node included). Meant for a timer; on a client of a shared brain the command sweeps that brain through the tool.

A document with no `expires_at` is served and kept exactly as before.
