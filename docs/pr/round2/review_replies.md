## #72 (`gc-04a-authz-tool-rules`)

Thanks. Amended in place, rebased on v2.135.0; the comments in `allowlist.go` and `rows.go` name `CallerScope` and `AuthorizeToolArgs`, and the commit message describes the allowlist.

1. The row guard withholds a foreign id with the bare `not found` and lets a missing one through to the tool, on the eleven row-id fields of the allowlist (`TestTheGuardWithholdsAForeignIdAndPassesAMissingOneOnEveryRowIdField`); the ports word the tool's own `not found` the same way, end to end in #73 and #74. `memory_save` now checks its `supersedes` targets before it writes, so a missing target leaves no new memory, as a foreign one does (`TestAMissingSupersedeTargetLeavesNoNewMemory`); that is a behaviour change for every caller, named under Breaking Changes. A list drops a foreign id as it drops a missing one (`TestMemoryGetByListHidesRowsOutsideTheCallerScopeAsMissing`). One asymmetry stays and the body names it as an oracle: on the four tools that create the row they name, and for the bucket a `session_id` names, a missing id is created and a foreign one refused, so the caller learns that the id is taken.
2. Walking the class behind this point (every argument that writes the shared graph), metadata was the smaller door: a declared entity is a node keyed by name across every collection. So `entities` and `relations` are refused whole to a confined key on `knowledge_save`, `knowledge_update` and `memory_save`; the engine's own extraction from the saved text stays. A document's `metadata` takes none of the chunk keys the engine writes (`document_id`, `chunk_index`, `graph_kind`), and no `metadata` map takes a key that starts with `_`; a filter map may name one, which is how a curator lists what waits (`TestAConfinedKeyDeclaresNoEntityOrRelationAndNoEngineKey`, `TestAFilterMayNameAnEngineKey`).

The same walk found more doors, all closed: `ingest_document` stores a `written_by` the caller sends, since only the four typed writes stamp it, so `written_by` and `updated_by` are refused in a confined key's metadata; `null` arguments are refused like any non-object; a gate sent under two spellings must be on under both; a document whose chunks are gone is withheld, since the facade cannot place it; and under a caller scope the facade itself holds a foreign `supersedes` target as not found (`TestASupersedeTargetOutsideTheCallerScopeIsNotFound`). And `search_graphrag_lexical` with `return_paths` ran path retrieval over the shared graph with no collection, so the four path arguments are refused (`TestPathRetrievalIsRefusedToAConfinedKey`); and `memory_get` with both `memory_id` and `memory_ids` read one while the guard read the other, so a confined key sends one form (`TestMemoryGetTakesOneFormFromAConfinedKey`).

Integration with #75–#77: this head classifies nothing of theirs, since their arguments are not on `main`. Whichever stack lands second adds its lines at the rebase, and the completeness test says which; I keep that classification ready on my side.

Thirty-seven hand mutations for the amendment, thirty-seven killed, each against a named test; the list is in the body.
