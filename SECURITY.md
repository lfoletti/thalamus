# Security policy

## Report a defect

Do not open a public issue for a security defect. Use the private report of GitHub: **Security**, then **Report a vulnerability**, on this repository.

Give the version or commit, the steps that show the defect, and what an attacker can do with it. You get an answer within 7 days.

A defect of CortexDB itself goes to the CortexDB maintainer, as that project asks.

## Supported versions

Thalamus is a work in progress. Only the head of `main` gets fixes.
